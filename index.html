Controls

  • Drag components to move. Click an Input to cycle T → 0 → +1.
  • To wire, click an output pin then an input pin.
  • Drag on empty space to pan the canvas. Shift+drag rect-selects.
  • Del deletes. Esc cancels wiring. Space+drag also pans. Wheel zooms.
  • Right-click deletes the component/wire under the cursor — toggle it with Right-click delete in the palette.
  • Step advances one clock tick (latches flip-flops, ticks clocks).
  • Info opens the component reference — select a component first to jump straight to its page.

Build a gate

Define a new ternary gate by filling in its truth table. Click cells to cycle T → 0 → +1. The resulting gate is a behavioural component — the simulator evaluates it by table lookup, not by an internal circuit of MIN/MAX/STI primitives.

Self-tests

Pure-function checks on the simulator's data path. These verify the math, not the UI. A failure means the simulator is producing wrong values somewhere — fix it before trusting any circuit you draw.

Pack into subcircuit

Selected components become a reusable block. INPUTs in the selection become input pins; OUTPUTs become output pins. Set a name (and optionally rename pins below) before packing.
